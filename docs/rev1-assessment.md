# Rev 1: is it impressive?

Rev 1 was made to test how far PCB work can go when the circuit is written as
code and every step is checked by a tool. This is an honest grade of the
result, not a sales page. It has not been built.

## What is genuinely strong

- **Reproducible from one file.** `hardware/rev1/circuit.py` defines every
  part and net. The schematic, placement, routing, ERC, DRC and renders are
  regenerated by `scripts/rev1.sh` in one command.
- **Tests tie the board to the firmware.** 15 circuit tests check, among other
  things, that every switch reaches exactly one GPIO, that the pin map equals
  `firmware/atelier6k/keyboard.json`, and that the LED order in the firmware
  follows the physical chain. A change on either side that breaks the other
  fails a test.
- **Clean checks.** ERC 0; netlist matches (24 nets, 102 pins); DRC 0 errors,
  0 unconnected, schematic parity 0; 413 track segments, 64 vias.
- **Every rev 0 power fault fixed.** 500 mA polyfuse, one LED chain with a
  100 nF capacitor at each LED and a bulk capacitor, a 74AHCT1G125 to lift LED
  data from 3.3 V to 5 V, a brightness cap.
- **A real mechanical fix.** The RP2040-Zero did not fit above the keys, so the
  keys moved down 12.7 mm, the module hangs under the board in a notch, and
  the case was regenerated around it with holes for BOOT and RESET.
- **A router written for the job.** Freerouting could not be run here, so the
  board is routed by a small A* maze router (`route.py`) with turn costs, vias
  and power-first ordering, judged by KiCad's DRC.

## What is ordinary

- **The circuit is simple.** Nine switches to ground on direct pins and one LED
  chain, on a ready-made MCU module. The hard parts of a keyboard PCB (USB
  layout, the MCU's power and clock) live on the module, not on this board.
- **The routing is correct but not beautiful.** A grid router makes extra
  bends and more vias (64) than a person would (rev 0 needed 28). A human
  pass would shorten it.
- **The schematic is a parts list.** Each pin has a labelled stub; it is
  correct and netlist-exact, but it does not read like a hand-drawn schematic.

## What is still open

- **LED pinout.** SK6812MINI-E datasheet revisions number the pins
  differently. The footprint must be checked against the drawing of the exact
  part bought.
- **Module dimensions.** The notch and the BOOT/RESET holes come from the
  Waveshare drawing, not from a measured module.
- **Fabrication package: done.** `scripts/fab.sh rev1` builds Gerbers, drill, JLCPCB BOM and CPL, the plate Gerbers and the case DXF (see [How to order](rev1-board.md#how-to-order)).

## Grade

As a test of PCB capability: **B+.** The process is the impressive part:
a fully generated, tested, DRC-clean board in which the firmware and the
hardware cannot drift apart. The board itself is deliberately simple, so it
does not prove high-speed layout, analog design or MCU bring-up. Rev 2
(Hall effect, 8 kHz USB High Speed, six analog sensors) is where those get
tested.
